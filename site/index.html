A 3D note space for Obsidian

Constellation 3D

See how your notes connect, travel through your vault, and explore folders as moving constellations. Follow these steps once; no coding or build tools required.

Download latest plugin View source Need help?
Before you start: This is an early community plugin. It is not yet listed in Obsidian's Community Plugins browser, so install it manually below.

Download the plugin

Click Download latest plugin at the top of this page. Open the downloaded constellation-3d.zip file to unzip it. You should see main.js, manifest.json, and styles.css.

Open your vault's plugins folder

Open the folder where your Obsidian vault is stored. Inside it, open .obsidian, then plugins. If plugins is missing, create that folder.

On a Mac

In Finder, open your vault folder and press Command + Shift + . to show hidden folders.

On Windows

In File Explorer, open your vault folder. Select View → Show → Hidden items.

Put the plugin files in the right place

From the unzipped download, copy these three files into a new folder named constellation-three-d inside .obsidian/plugins:

main.js   manifest.json   styles.css

Your final folder should look exactly like this:

Your vault/.obsidian/plugins/constellation-three-d/main.js
Your vault/.obsidian/plugins/constellation-three-d/manifest.json
Your vault/.obsidian/plugins/constellation-three-d/styles.css

Do not leave the files buried inside another nested project folder.

Turn it on in Obsidian

In Obsidian, open Settings → Community plugins. If Restricted mode is on, turn it off and confirm. Under Installed plugins, find Constellation 3D and switch it on.

Open your 3D note space

Press Command/Ctrl + P to open the command palette, search for Open Constellation 3D, and select it. You can also use the orbit icon in the left ribbon.

Something went wrong?

Constellation 3D is not listed? Confirm that the folder is named constellation-three-d and that manifest.json is directly inside it. Then restart Obsidian.

The graph is empty? Add links between notes using Obsidian's [[double brackets]], then click Refresh in Constellation 3D.

Still stuck? Open an issue on GitHub and include your operating system and Obsidian version.

Constellation 3D is a community plugin. Your notes stay in your vault; the plugin does not send them to a server.
